# Build MediaMTX MOQ Subscriber and Publisher Library

Creates module builds of the [MediaMTX MoQ client](https://github.com/bluenviron/mediamtx/tree/main/internal/servers/moq) for [MediaMTX](https://mediamtx.org/)

For now requires the [MediaMTX Fork](https://github.com/danrossi/mediamtx/tree/moq-js-modules) branch with the es module fixes for the client libraries.

## Requirements

npm
vite

## Setup

```
./setup.sh
```

## Update Packages

```
./update.sh
```

## Building

```
npm run build
```
